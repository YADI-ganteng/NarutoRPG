# Si Pintar Bot 🤖

Bot Telegram pintar yang bisa diajak ngobrol, main game, dan banyak lagi!

## Fitur
- 💬 Chat AI sederhana
- 🎮 Game (Tebak Angka, Kuis, Suit)
- 😂 Jokes & Fakta
- 📊 Sistem Level & Poin
- 😊 Mood System

## Cara Menjalankan
1. Install dependencies: `pip install -r requirements.txt`
2. Jalankan: `python bot/pintar_bot.py`

## Perintah
- /start - Mulai bot
- /help - Bantuan
- /game - Main game
- /jokes - Jokes lucu
- /info - Info pengguna
